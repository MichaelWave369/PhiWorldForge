# Architecture

```text
Image, sketch, concept / provider generation (future)
                  |
        Existing GLB/OBJ, SPZ, audio exports
                  |
            ingest_exports (working)
                  v
         phiworldforge.scene/0.1
                  |
         validation + packaging
                  |
           +------+-------+
           |              |
     Three.js viewer    Unreal importer
     (demo running)     (planned)
           |
       WebXR button
       (experimental)
```

The Python core has no network dependencies or cloud credentials. Provider/engine connectors must adapt to the scene contract, not bypass it. Scene validation is a prerequisite, not proof that rendering, physics, VR compatibility or legal rights are correct.

The ARCLight demo contains handcrafted geometry. It is **not** presented as generated by Image-Blaster.
